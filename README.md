# Oreamo Workspace

Workspace for shared configuration across Oreamo services.

## Repositories

| Directory        | Description                                   | Repository                                  |
| ---------------- | --------------------------------------------- | ------------------------------------------- |
| `oreamo-client/` | Admin web client (React, TypeScript, Vite)    | https://github.com/oreamo/oreamo-client     |
| `oreamo-server/` | Admin API server (Spring Boot, MyBatis, MySQL) | https://github.com/oreamo/oreamo-server     |
| `oreamo-agent/`  | Admin API server (FastAPI, SQLAlchemy, MySQL) | https://github.com/oreamo/oreamo-agent      |

Each service is an independent git repository and is excluded from this repository via `.gitignore`.
